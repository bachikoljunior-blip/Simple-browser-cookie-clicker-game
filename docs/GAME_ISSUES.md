## 2. 色素材の加算ボーナス oreAdd がドロップ式の外に足されており、靴v6を1個作るだけで素材経済が消える

**重要度** CRITICAL　**観点** `equip-material`

### 該当箇所

```
EQUIP2_FX.shoes[5] (`{ m:"B", up:["oreAdd",3], down:["goldenAmtMul",0.9] }`) play.html:11177 / ドロップ式 `oreExp = (MAT_DROP_BASE * strength * matRarityDrop(oreId) + equip2Fx().oreAdd) * count` play.html:9817・9826 / コスト重み `EQ2_COST_UNIT.oreAdd = 0.1` play.html:11220
```

### 実測値

色素材の素の期待値は MAT_DROP_BASE=0.20 × 強さ(√hpMul) × レア度。ロスター加重平均で c帯(t1-4)=0.250個/spawn、r帯(t5/t6, レア度0.35)=0.087個/spawn。出現間隔42-60秒(levelFactor込み平均46秒)＝78 spawn/時なので、素の入手は c帯 19.6個/時、r帯 6.9個/時。ここに oreAdd はレア度も強さも通さない生の加算として入る。shoes_t1_v6「大鉱脈の鉄靴」は oreAdd=3(t1、スケール1.5^0)、コストは ore_t1×15 + butter×6 の計21個。装備すると c帯 4.57個/spawn(素の18.3倍)、r帯 4.41個/spawn(素の50.4倍)。t6版(oreAdd=3×1.5^5=22.8)では c帯 33.1個/spawn(132倍)、r帯 32.9個/spawn(376倍)。回収は5体。具体例: t6のv1装備を9枠そろえる ore_t6 は計79個で、素なら 2.4個/時 ＝33時間、shoes_t1_v6 を1個作った直後は 120個/時 ＝39分(×51)。コストモデル側は oreAdd の単位重みを 0.1 と置いており、+3個/体(＝色素材収入18倍)を「素材ドロップ+30%」と同格に値付けしている。

### 何が起きているか

## 3. 転生PTの使い道が71ノード計15.5億PTで打ち止め。転生97回目以降、PTは獲得しても永久に使い道がない完全な死に通貨になる

**重要度** CRITICAL　**観点** `prestige-loop`

### 該当箇所

```
totalPrestigeFromCookies() play.html:15326-15337(PT = floor(14 * (runCookies/1e4)^0.085))、SKILL_NODES play.html:6602-6700、PTの唯一の消費先 skillCanBuy() play.html:13184 / takeSelectedSkill() play.html:13232、PRESTIGE_COST_TABLE play.html:8649
```

### 実測値

PTの sink は state.skills[id]=true のブール71ノードのみ(レベル制なし・他の消費先はソース全体で0箇所)。71ノードの合計コストは実測 1,555,826,482 PT。コストテーブル通りに周回した場合の累積PT: 転生40回=3.65e4(全体の0.002%)、60回=3.31e6(0.2%)、80回=1.09e7(0.7%)、97回=2.31e9 → ここで71/71ノード完成。ところが獲得式は指数0.085 × コストが1周2桁伸びる領域に入るため、97回目の1周だけで7.61e8 PT(ツリー全体の49%)、98回目は1.125e9 PT(ツリー全体の72%を1周で)。115回目の1周は8.73e11 PT = ツリー全体の561倍、累積2.70e12 = 全sinkの1732倍。

### 何が起きているか
