# Play Console 各申告フォームの回答シート

「アプリのコンテンツ」以下のフォームは全部埋めないと公開できません。
このアプリの実装（`play.html` / `firestore.rules` / `privacy.html`）に照らした回答をまとめました。
そのまま選んでいけば埋まります。**内容を変えたら、この表も更新してください。**

| 項目 | 回答 |

## 2. アプリのアクセス権限

| 項目 | 回答 |
|---|---|
| アプリの全機能に制限なくアクセスできますか | **はい、すべての機能が制限なく利用できます** |

根拠: ログインは任意で、クラウド保存以外のすべての機能はログイン無しで遊べます。
そのため審査用のテストアカウント提出は不要です。

## 3. 広告

| 項目 | 回答 |
|---|---|
| アプリに広告が含まれていますか | **いいえ** |

根拠: **Google Play 版では広告を一切出しません。** `play.html` の `<head>` で
Play 版（TWA）と判定した場合は AdSense のスクリプト自体を読み込まず、
広告表示（`adBreak`）も呼びません。広告の代わりに「周回スタートは24時間に1回」の
制限を設け、買い切りのアプリ内アイテムで解除できるようにしています。

※ ブラウザ版（cookiestrateger.com）は従来どおり AdSense を表示しますが、
これはアプリ外のウェブサイトなので Play の広告申告には影響しません。

## 4. コンテンツのレーティング（IARC 質問票）

| 質問 | 回答 |
|---|---|
| カテゴリ | ゲーム（Game） |
| 暴力表現 | なし |
| 性的表現 | なし |
| 不適切な言葉 | なし |
| 規制対象の物質（薬物・アルコール・タバコ） | なし |
| ギャンブル（現実の金銭を賭ける要素） | **なし** |
| シミュレートされたギャンブル | **なし** |
| ユーザー間の交流機能 | **なし**（チャット・掲示板・フレンド機能はありません） |
| ユーザーの現在地の共有 | なし |
| 個人情報の共有 | なし |
| デジタルコンテンツの購入 | **あり**（スタート制限を解除する買い切り） |

「クッキーモンスターを倒す」要素は抽象的なアイコンの撃破で、流血・負傷表現はないため
暴力表現は「なし」で問題ありません。想定される結果は全年齢（IARC 3+ / CERO A 相当）です。

## 5. ターゲットユーザーとコンテンツ

| 項目 | 回答 |
|---|---|
| 対象年齢層 | **13〜15歳 / 16〜17歳 / 18歳以上** にチェック（12歳以下は入れない） |
| 子ども向けにデザインされていますか | **いいえ** |
| ストアでの表示 | 「ファミリー向けプログラムに参加しない」 |

**12歳以下を含めないことを強く推奨します。** 含めるとファミリー向けプログラムの対象になり、
審査項目が増えるほか、アプリ内購入の見せ方にも追加の要件がかかります。
（Play 版は広告を出さないので、広告まわりの規制自体は問題になりません）

## 6. データセーフティ

### 収集するデータ

| データの種類 | 収集するか | 用途 | 必須か | 共有するか |
|---|---|---|---|---|
| 個人情報 → **ユーザーID** | **はい** | アプリの機能（クラウドセーブの本人特定） | 任意 | いいえ |
| 個人情報 → メールアドレス | いいえ※ | — | — | — |
| アプリのアクティビティ → **アプリ内のその他の操作** | **はい** | アプリの機能（セーブデータの同期） | 任意 | いいえ |
| デバイスID | いいえ | — | — | — |
| 位置情報 / 連絡先 / 写真 / 音声 / 健康 | いいえ | — | — | — |

※ Firebase Authentication の仕組み上、ログインすると `email` / `displayName` が
クライアント側で参照可能になります。ただしこのゲームは Firestore に保存するのは
`saves/{uid}` のセーブデータのみで、メールアドレスや表示名は保存していません
（`pushCloudSave` が保存するのは `buildSavePayload()` の内容だけ）。
表示名は設定画面に出すだけで送信も保存もしません。**厳密に安全側へ倒すなら
「メールアドレス」も「収集する / 用途: アプリの機能 / 共有しない」に含めてください。**
迷ったら含める方が安全です（過少申告はポリシー違反、過剰申告は違反になりません）。

### 広告に関する申告

**不要です。** Play 版は広告を出さず、広告 SDK も読み込まないため、
広告目的でのデータ収集・共有の申告は発生しません。

## 9. アプリ内アイテム（収益化 → アプリ内アイテム）

| 項目 | 値 |
|---|---|
| 商品 ID | **`unlimited_start`** |
| 種類 | 1回限りの購入（買い切り・managed product） |
| 名前 | スタート制限の解除 |
| 説明 | 24時間に1回の周回スタート制限がなくなり、いつでも周回を始められます。 |
| 価格 | 任意（例: ¥370） |
| ステータス | **有効** |

商品IDは `play.html` の `PRODUCT_ID = "unlimited_start"` にハードコードされています。
**1文字でも違うと購入できません。** また販売者アカウント（Payments profile）の設定が前提です。

```

  ↓

  ↓
製品版アクセスの申請（審査は通常7日以内）
  ↓
製品版公開
```
