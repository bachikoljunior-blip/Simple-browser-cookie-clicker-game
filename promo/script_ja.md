# YouTube Shorts プロモ動画 — 台本と掲載文

対象ファイル：`promo/cookie_strateger_short.webm`（1080×1920 / 約41秒 / **音声あり**）

音声はゲーム自身のBGMと効果音です。このゲームは音を音源ファイルではなくその場で合成しているので、
実際に鳴っている音をそのまま録っています。カットの切り替わりには効果音を足してあります。
ピーク −3.4dBFS・平均 −19dBFS でクリップなし、このまま投稿できる状態です。

テロップも焼き込んであります。実況の声を重ねたい場合は、下の台本を読んで既存の音の上に乗せてください
（ゲームのBGMを −18dB ほど下げると声が通ります）。

---

## 1. カット構成 —— 各カットで「何が面白そうに見えるか」

尺の都合で全機能は入れていません。**画にした瞬間いちばん引きが強いもの**だけを選んでいます。

| # | 見せているもの | それを選んだ理由 |
|---|---|---|
| 1 | 所持クッキー **100正** | 数が大きいだけの放置ゲーは無数にあるので、「大きい」ではなく**単位が読めない**ことを掴みにした。クッキー画面を全画面にして、数字と絵だけで1画面を占めるようにしている。「“正”って知ってます?」は質問なので、答えを見るために指が止まる |
| 2 | クッキー25枚まで巻き戻し | 1カット目との落差そのものが引き。所要時間（「3分前」など）は出していない。実際にその速さでは伸びないため |
| 3 | タップ→設備→毎秒 | あえて平凡に、短く。「ふつうの放置ゲー」と言い切って、次で裏切るための踏み台 |
| 4 | **モンスター生成ノルマ** | 他の放置ゲーに無い唯一の仕組み。「強化が止まる」という**ルールの説明**ではなく「モンスターが来なくなる」という**結果**で言う方が刺さる |
| 5 | 金のクッキー → 群れ＋ボス | 画面がいちばん賑やかになる瞬間。ボスは炎のエフェクトとHP数千万で単体でも絵になる |
| 6 | 装備レシピ **486種類** | クリッカーで486は想定外の数字。具体的な数を出すと「思ったより深い」が一発で伝わる |
| 7 | **料理でノルマの進行を遅らせる** | 4カット目に張った「ノルマがきつい」を回収する。対抗手段がある＝詰まないと分かると、遊ぶ側の不安が消える。料理の絵も一枚一枚きれい |
| 8 | 一覧画面の倍率の壁 | x13351.000 / x590157.128 が並ぶ画。**数字を見て積み上げたい層**に一番効く。「なんとなく強くなった」で終わらない証拠として出す |
| 9 | 転生スキルツリー **71ノード** | 縦にパンして物量で殴る。文字より画で「多い」を伝えられる唯一のカット |
| 10 | 100正に戻る | 1カット目の回収。ここで一周して気持ちよく終わる |
| 11 | テスター募集 | 動画の目的。赤枠＋点滅＋▼で概要欄へ送る |

## 2. 実況台本（ナレーション）

タイムコードは目安です。テロップの切り替わりに合わせて読んでください。

| 時間 | 読み上げ |
|---|---|
| 0:00–0:02 | 「“正”って単位、知ってますか。10の42乗です。放置ゲーの所持数がここまで来ました。」 |
| 0:02–0:07 | 「最初はこうでした。クッキー25枚。タップ1回で1クッキー。」 |
| 0:07–0:11 | 「設備を買うと毎秒が勝手に増えていく。ここまでは、ふつうの放置ゲーです。」 |
| 0:11–0:16 | 「本題はここから。このゲーム、モンスター生成ノルマがあります。生産が遅れると、モンスターが来なくなる。**放置ゲーなのに、放置したら終わります。**」 |
| 0:16–0:22 | 「金のクッキーを拾うと生産が跳ねて、モンスターを殴ると素材が出る。群れで来ることもあるし、ボスも来ます。」 |
| 0:22–0:28 | 「集めた素材で装備を作れます。レシピは486種類。そして料理。これがノルマの進行を遅くしてくれます。」 |
| 0:28–0:35 | 「研究で生産の計算式そのものを書き換えて、効いている倍率は全部この画面で確認できます。」 |
| 0:35–0:37 | 「そして転生。スキルツリーのノードは71個。取る順番で次の周回が別ゲーになります。」 |
| 0:37–0:38 | 「で、さっきの数字に戻ります。」 |
| 0:38–0:41 | 「クッキーストラテジャー、現在Google Playでクローズドテスト中です。テスターを募集しているので、応募方法はチャンネルの概要欄を見てください。」 |

### 収録のコツ
- 0:00 の1行は**速く、質問として**。Shorts は最初の1.5秒で離脱が決まります。
- ゲームのBGMがすでに鳴っています。無音を待たず、その上に重ねる前提で読んでください。
- 「放置したら終わります」の前で一拍おく。ここが動画で一番効く行です。
- 「486種類」「71個」は**数字を強く**読む。具体的な数はそれだけで説得力になります。
