# YouTube Shorts プロモ動画 — 台本と掲載文

対象ファイル：`promo/cookie_strateger_short.webm`（1080×1920 / 約43秒 / 音声なし）

動画にはテロップが焼き込まれているため、**音声なしのまま投稿しても内容が伝わります**。
実況音声を乗せる場合は、下の台本をそのまま読んでください。尺は各シーンのテロップに合わせてあります。

タイムコードは目安です。テロップの切り替わりに合わせて読んでください。

### 収録のコツ
- 0:00 の1行は**巻き舌気味に速く**。Shorts は最初の1.5秒で離脱が決まります。
- 「放置しっぱなしだと負けます」は一拍おいてから言うと刺さります。
- BGM を足す場合は −18dB 程度に抑え、ナレーションを前に出してください。
