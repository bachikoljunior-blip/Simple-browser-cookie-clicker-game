# YouTube Shorts プロモ動画 — 台本と掲載文

対象ファイル：`promo/cookie_strateger_short.webm`（1080×1920 / 約43秒 / **音声あり**）

音声はゲーム自身のBGMと効果音です。このゲームは音を音源ファイルではなくその場で合成しているので、
実際に鳴っている音をそのまま録っています。カットの切り替わりには効果音を足してあります。
ピーク −3.5dBFS・平均 −19dBFS でクリップなし、このまま投稿できる状態です。

テロップは YouTube のUI（下のタイトル・チャンネル行、右の高評価/コメント列）に
かからない位置に置いてあります。トリミングや位置調整をすると隠れる恐れがあります。

テロップも焼き込んであります。実況の声を重ねたい場合は、下の台本を読んで既存の音の上に乗せてください
（ゲームのBGMを −18dB ほど下げると声が通ります）。

## 1. カット構成 —— 各カットで「何が面白そうに見えるか」

尺の都合で全機能は入れていません。**画にした瞬間いちばん引きが強いもの**だけを選んでいます。

| # | 見せているもの | それを選んだ理由 |
|---|---|---|
| 1 | 所持クッキー **100正** | 数が大きいだけの放置ゲーは無数にあるので、「大きい」ではなく**単位が読めない**ことを掴みにした。クッキー画面を全画面にして、数字と絵だけで1画面を占めるようにしている。「“正”って知ってます?」は質問なので、答えを見るために指が止まる |
| 2 | クッキー25枚まで巻き戻し | 1カット目との落差そのものが引き。**1カット目と同じ全画面のまま**にして、構図も数字の位置も揃えている（画面が変わると「別の場面」に見えて対比が成立しない）。所要時間（「3分前」など）は出していない。実際にその速さでは伸びないため |
| 3 | タップ→設備→毎秒 | あえて平凡に、短く。「ふつうの放置ゲー」と言い切って、次で裏切るための踏み台 |
| 4 | **生産ペースのノルマ** | 他の放置ゲーに無い唯一の仕組み。ルールの説明ではなく「モンスターが出なくなる」という**結果**で言う。ただし「放置したら終わる」とは書かない（実際に終わるのはその周回のモンスター出現だけで、生産は続きオフラインでも貯まる。放置ゲーを探している層に「放置できない」と伝わるのは事実と違ううえ逆効果） |
| 5 | 金のクッキー → 群れ＋ボス | 画面がいちばん賑やかになる瞬間。ボスは炎のエフェクトとHP数千万で単体でも絵になる。金のクッキーはゲームが盤面のどこにでも出すので、収録では見える位置に置き直している（下端に出ると小さいうえ YouTube のUIに隠れる）。モンスターは必ず倒れて素材が落ちるようにしてある（「殴ると素材が出る」と言っておいて何も起きないのが一番弱い） |
| 6 | 装備レシピ **486種類** | クリッカーで486は想定外の数字。具体的な数を出すと「思ったより深い」が一発で伝わる |
| 7 | **料理でノルマの進行を遅らせる** | 4カット目に張った「ノルマがきつい」を回収する。対抗手段がある＝詰まないと分かると、遊ぶ側の不安が消える。料理の絵も一枚一枚きれい |
| 8 | 一覧画面の倍率の壁 | x13351.000 / x590157.128 が並ぶ画。**数字を見て積み上げたい層**に一番効く。「なんとなく強くなった」で終わらない証拠として出す |
| 9 | 転生スキルツリー **71ノード** | 縦にパンして物量で殴る。文字より画で「多い」を伝えられる唯一のカット。ジャンル外の人には「転生」が“進行が消える”と読まれるので、得られるもの（次の周回が速くなる）を必ず言う |
| 10 | 100正に戻る | 1カット目の回収。ここで一周して気持ちよく終わる |
| 11 | テスター募集 | 動画の目的。「クローズドテスト中」は“未完成でまだ遊べない”、「テスター」は“報告作業がある”と読まれやすいので、募集の理由（公開に必要）・やること（14日間入れたまま）・対象（Android）を先に出し、赤枠には行動だけを残す |

## 2. 実況台本（ナレーション）

タイムコードは目安です。テロップの切り替わりに合わせて読んでください。

| 時間 | 読み上げ |
|---|---|
| 0:00–0:03 | 「“正”って単位、知ってますか。10の42乗です。放置ゲーの所持数がここまで来ました。」 |
| 0:03–0:05 | 「最初はこうでした。クッキー25枚。」 |
| 0:05–0:08 | 「タップ1回で1クッキー。設備を買うと毎秒が勝手に増えていく。ここまでは、ふつうの放置ゲーです。」 |
| 0:08–0:12 | 「本題はここから。このゲーム、生産ペースにノルマがあります。遅れると、その周回はモンスターが出なくなる。置いておくだけでも増えますが、**ただ放置だと伸び切りません。**」 |
| 0:12–0:18 | 「金のクッキーを拾うと生産が跳ねて、モンスターを殴ると素材が出る。群れで来ることもあるし、ボスも来ます。」 |
| 0:18–0:24 | 「集めた素材で装備を作れます。レシピは486種類。そして料理。これでノルマをゆるめられます。」 |
| 0:24–0:30 | 「研究を買うと生産の計算式が変わって、効いている倍率は全部この画面で確認できます。」 |
| 0:30–0:37 | 「そして転生。スキルツリーのノードは71個。次の周回は確実に速くなります。取り方は何度でも組み直せます。」 |
| 0:37–0:40 | 「で、さっきの数字に戻ります。」 |
| 0:40–0:43 | 「クッキーストラテジャー。Android版の公開に必要なテスターを募集しています。14日間インストールしたままにしていただくだけです。応募方法はチャンネルの概要欄を見てください。」 |

### 収録のコツ
- 0:00 の1行は**速く、質問として**。Shorts は最初の1.5秒で離脱が決まります。
- ゲームのBGMがすでに鳴っています。無音を待たず、その上に重ねる前提で読んでください。
- 「ただ放置だと伸び切りません」の前で一拍おく。ここが動画で一番効く行です。
- 「486種類」「71個」は**数字を強く**読む。具体的な数はそれだけで説得力になります。

## 5. チャンネル概要欄に載せるテスター募集文（要記入）

動画の最後で「応募方法はチャンネル概要欄に」と案内しています。**投稿前にチャンネル概要欄を更新してください。**

あわせて、**動画の説明欄にも同じ内容を入れることを強くおすすめします**（上の §4 に枠を用意しました）。
Shorts からチャンネル概要欄へ行くには「アイコンをタップ → チャンネル → 概要」と3手かかりますが、
動画の説明欄はタイトルをタップするだけで開きます。導線が短いほど応募は増えます。

Google Play の個人アカウントで製品版を公開するには、クローズドテストで
**12人以上のテスターが14日間連続でオプトイン**している必要があります（`PLAY_STORE.md` §7 参照）。
テスターは Android 端末を持っている方に限られます（iPhone はカウントされません）。

以下の `<>` を実際の値に置き換えて使ってください。

```
■ クッキーストラテジャー テスター募集中

Google Play のクローズドテストに参加していただける方を募集しています。
参加は無料、いつでも抜けられます。

【条件】
・Android 端末をお持ちの方（iPhone はテスターに参加できません）
・Google アカウントをお持ちの方
・14日間、アプリをインストールしたままにしていただける方
 （毎日プレイする必要はありません）

【参加方法】

  <Googleグループの参加URL>

  <Play Console が発行するオプトインURL>

【お願い】
```
