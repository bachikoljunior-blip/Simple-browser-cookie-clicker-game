# YouTube 投稿用テキスト

宣伝動画を YouTube に上げるときの「タイトル・説明・タグ」をここにまとめています。
文字数は YouTube の上限に収まるよう調整済みです（`node youtube/yt.mjs check` で再検証できます）。

`yt.mjs upload` はこのファイルを読んでそのまま投稿に使うので、
**コードブロックの中身だけ**を書き換えてください（見出しの形は変えないでください）。

---

## タイトル（上限100文字）

```
【無料ブラウザゲーム】クッキーストラテジャー｜タップして焼いて、ノルマ管理で伸ばす放置クリッカー
```

短くしたい場合（検索結果で末尾が切れにくくなります）：

```
クッキーストラテジャー｜無料で遊べる放置クリッカー×ノルマ管理
```

---

## 説明（上限5000文字）

```
インストール不要・登録不要。ブラウザを開いた瞬間から遊べる無料の放置クリッカー「クッキーストラテジャー」の紹介です。

▼ いますぐ遊ぶ（無料）
https://cookiestrateger.com/

■ どんなゲーム？
画面中央のクッキーをタップするとクッキーが手に入ります。貯まったクッキーで「強い指」「おばあちゃん」「オーブン」「工場」といった設備を買うと、毎秒の自動生産が増えていきます。あとは眺めているだけでもクッキーは増え続けるので、すきま時間に少しずつ進められます。

■ ただ放置するだけでは伸びない
このゲームには「モンスター生成ノルマ」があります。一定の生産ペースを保っている間だけ強化が進み、ペースを落とすと止まってしまう仕組みです。どこで設備に投資し、どこで一気に稼ぐか。放置ゲームでありながら、判断がそのまま結果に出ます。

■ 周回と転生スキルツリー
行き詰まったら転生。積み上げた生産量に応じてスキルポイントが手に入り、スキルツリーで次の周回が一段速くなります。研究・注文・設備熟練・図鑑と、伸ばす方向は一つではありません。

■ こんな人におすすめ
・短時間でも進む放置ゲームを探している
・クリッカー系は好きだが、完全放置だと物足りない
・インストールや会員登録をしたくない

■ 動作環境
PC・スマートフォンのブラウザで動きます。進行状況は自動で保存されます。

#放置ゲーム #クリッカー #ブラウザゲーム #無料ゲーム #インディーゲーム
```

## 公開設定

`promo/youtube/.env` の `YT_PRIVACY` で切り替えます（既定は `private`）。

| 値 | 意味 |
|---|---|
| `private` | 自分だけが見られる。まず限定で確認したいとき |
| `unlisted` | URL を知っている人だけ見られる |
| `public` | 全体公開 |

いきなり `public` にせず、`private` で上げて YouTube Studio で見た目を確認してから
公開設定を変えることをおすすめします。
