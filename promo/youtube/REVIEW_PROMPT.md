崩れます。下の `---` から下を**そのまま** `Agent` の prompt にして、
`<frames>` と `<claims>` だけ `review.mjs prepare` の出力で置き換えてください。

## 答えてほしいこと

1. **あなたは何秒でスワイプしますか。その秒に何が起きていますか。**
   「最後まで見る」なら、なぜ指が止まったのかを書いてください。
2. **最初の1.5秒のフレームだけを見て、これが何のゲームか分かりますか。**
   分からないなら、何が足りないですか。
3. **主張（上の claims）と、実際に映っているものは合っていますか。**
   映っていないことを言っていたら、それはどれですか。
4. **この動画がつまらないとしたら、いちばんの理由は何ですか。** 1つに絞ってください。
5. **同じ素材で、あなたならどこをどう変えますか。** 具体的に1つだけ。

## 出力

最後に、次の形の**JSONだけ**を ``` で囲んで出してください
（前後に説明を書いてよいが、JSONブロックは1つだけ）。

```
{
  "verdict": "pass" または "fail",
  "swipeAt": 秒（数値。最後まで見たなら null）,
  "reasons": ["理由を短く。2〜4個"],
  "fix": "同じ素材でできる、いちばん効く直しを1文で"
}
```

**判定の基準**: これがフィードに流れてきたとき、**指が止まって最後まで見られるか**。
「悪くない」は pass ではありません。**止まらないなら fail です。**
甘い評価は誰の役にも立ちません。落とすべきなら落としてください。

## 判定を記録する（子がやる）

レビュアーが返した JSON を、そのまま標準入力に流す:

    printf '%s' '<レビュアーが返したJSON>' | node /home/user/Simple-browser-cookie-clicker-game/promo/youtube/review.mjs record

`record` は **mp4 の sha256 を自分で計算して**判定に焼き付けます。
レビュアーの申告ではないので、**別の take の合格が今回の投稿を通すことはできません。**

`autopost.mjs` は投稿の直前に `review.mjs check` を呼び、
**判定が無い・別の切り口のもの、のどちらかなら例外で止まります。**
**不合格では止まりません**（2026-08-10 夕に拒否権を外した。理由は RUNBOOK §3-2）。

**この節は 2026-08-11 に直しました。** ここには「不合格なら投稿しない」「sha256 が
変わるので前の合格は使えない」と書いてあり、**どちらも同じ日にコードで変わったのに
この文書だけ古いまま残っていました。** 照合は sha ではなく切り口の id です。
**手順が2か所にあると片方が古くなる** ——— 判定の正本は `review.mjs` のコードと
RUNBOOK §3-2 で、ここはその写しです。次に変える人は両方直すこと。
