# プロモ映像（YouTube ショート用）

クッキーストラテジャーの紹介動画を、**実際に動いているゲーム画面**から自動で作り直せるようにしたものです。
出力は縦 1080×1920 / 30fps / 50秒。YouTube ショートにそのまま投稿できます。

| ファイル | 中身 |
|---|---|
| `out/promo_shorts_1080x1920.mp4` | 完成品（BGM 入り）— **これを投稿します** |
| `out/promo_shorts_1080x1920_silent.mp4` | 同じ映像の無音版（自分で音楽を付けたいとき用・リポジトリには入れていません。`build.sh` で生成されます） |
| `out/thumbnail_1080x1920.jpg` | カスタムサムネイル用の静止画 |

## 作り直す

```bash
bash promo/build.sh                 # 収録からエンコードまで一括（PC で 10 分ほど）
bash promo/build.sh --skip-capture  # 収録済み素材のまま、テロップや尺だけ直す
```

必要なもの：`node`、`ffmpeg`、`python3`、そして `node_modules/playwright-core`（このリポジトリに同梱）。
日本語フォント（Noto Sans JP / SIL Open Font License 1.1）は `build.sh` が初回に取得します。

## 構成

```
promo/
  capture-gameplay.js  ゲームを実際に操作して、素材を JPEG 連番で収録する
  compositor.html      映像の組み立て台（ゲーム映像＋テロップ＋しめの画面）
  timeline.js          尺・カメラ・テロップ。すべて「時刻 t の関数」として書いてある
  render-video.js      compositor を 1 フレームずつ撮って mp4 に焼く
  make-music.js        BGM を合成して WAV に書き出す（既成曲を使わないので権利の心配がない）
  lib/seed.js          収録用のセーブ状態（設備の台数・研究・スキル・PT）
  lib/game.js          ゲーム起動と操作のヘルパー
  lib/recorder.js      CDP スクリーンキャストの受け皿
  build.sh             上の全部を順に回す
```

### 映っているもの

素材はすべて実プレイです。撮影前に周回を中盤相当まで進めておき（`lib/seed.js`）、
そのあとのタップ・購入・討伐・スキル取得は通常の入力で行っています。

| 秒 | 中身 |
|---|---|
| 0–6 | クッキー連打と金のクッキー（つかみ） |
| 6–14 | ① 設備をまとめ買いして毎秒が跳ねる → 全画面で 16 種類を一望 |
| 14–20 | ② 研究を解放して毎秒とダメージが伸びる → 研究一覧 |
| 20–30 | ③ ボスを連打で撃破 → 報酬を選ぶ |
| 30–38 | ④ 転生スキルツリーを引きで見せる → 実際に 1 つ取得 |
| 38–42 | タイトル画面 |
| 42–50 | Google Play テスター募集の案内（登録方法はチャンネル説明欄） |

カット位置は 120BPM（1小節＝2秒）の小節線に合わせてあり、`make-music.js` の
アレンジ切り替えと一致しています。尺や文言を変えるときは `timeline.js` の
`SECTIONS` と `make-music.js` の `CUE` を揃えてください。

### 文言を直したいとき

テロップは `timeline.js` の `seek()` 末尾にまとまっています。しめの画面（テスター募集）の
文言は `compositor.html` の `#cta` 以下にあります。

## 投稿するときのメモ

- ショートとして扱われる条件は「縦向き・60秒以内」。この動画は 50 秒なので条件を満たします。
- **チャンネルの説明欄に、テスター登録の手順とリンクを必ず入れてください。** 動画の最後で
  そこを見るように案内しています。
- タイトル例：`【放置ゲーム】タップして焼くだけ…のはずが数字が止まらない #Shorts`
- 説明欄に入れる項目の例：
  - ブラウザ版（インストール不要）: https://cookiestrateger.com/
  - Google Play クローズドテストの参加方法（Google グループ／メールアドレスの登録手順）
  - テスト参加用のオプトイン URL
